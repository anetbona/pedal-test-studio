# STRATEGY — PedalTest Studio

## Business Model Canvas

| Blok | Treść |
|------|-------|
| **Segmenty klientów** | Gitarzyści hobbyści-amatorzy kupujący kostki rozważnie; porównują brzmienie między producentami. Wykluczeni: profesjonaliści i użytkownicy modelerów. |
| **Propozycja wartości** | Interaktywny odsłuch kostki przed zakupem: ten sam riff w różnych ustawieniach gałek + wizualizacja ustawień. Docelowo: zdalne sterowanie prawdziwym hardware'em (nie symulacją) — kluczowy wyróżnik rynkowy. |
| **Kanały** | Webapp (otwarty portal, zero tarcia), społeczności gitarowe, YouTube/IG (kontrast wobec „nieskazitelnych" dem), partnerstwa z producentami. |
| **Relacje z klientami** | Self-service bez kont (MVP); później konta, rezerwacje slotów, NPS po sesji. |
| **Strumienie przychodów** | MVP: linki afiliacyjne / commission fee. Później: płatne minuty testowania na fizycznym rigu (freemium „na kawę": pierwsze sloty gratis, dalej ~5 USD/h; „ukradnij slot" 30 min / 20 PLN). |
| **Kluczowe zasoby** | Katalog kostek z nagraniami (jeden riff, ustawienia 2/6/9), grafiki i metadane gałek, anonimowe statystyki (dane do rozmów z producentami); później: fizyczny rig (kostki + mikser + MIDI). |
| **Kluczowe działania** | Produkcja treści (nagrania per kostka), rozwój portalu, pozyskiwanie partnerstw afiliacyjnych i producenckich. |
| **Kluczowi partnerzy** | Producenci efektów (Boss, Ibanez, EHX…), sklepy (Sweetwater, Guitar Center, sklepy PL) — programy afiliacyjne. |
| **Struktura kosztów** | MVP: czas na treści + hosting (znikomy — zero-dependency). Później: sprzęt (kostki, mikser, interfejs MIDI), streaming, płatności. |

## Value Proposition Canvas

| Strona klienta | Treść |
|----------------|-------|
| **Zadania klienta (jobs)** | Wybrać kostkę, która brzmi dobrze *dla jego ucha*; porównać modele różnych producentów; nie przepłacić. |
| **Bóle (pains)** | Dema na YT niereprezentatywne (post-produkcja, topowy sprzęt); brak sklepu w okolicy / brak możliwości testu; sample online w sztywnych ustawieniach; ryzyko nietrafionego zakupu. |
| **Korzyści (gains)** | Usłyszeć różnicę między ustawieniami i modelami przed zakupem; uczciwe porównanie (ten sam riff!); szybka droga do zakupu, gdy coś zagra. |

| Strona produktu | Treść |
|-----------------|-------|
| **Produkty i usługi** | Otwarty portal: katalog → podstrona kostki (grafika + animowane gałki + nagrania) → belka sklepów. |
| **Środki przeciwbólowe (pain relievers)** | Jeden riff w wielu ustawieniach = uczciwe porównanie; gałki pokazują dokładne ustawienia nagrania; zero kont i paywalli przed pierwszym dźwiękiem. |
| **Generatory korzyści (gain creators)** | Natychmiastowe przełączanie nagrań (porównanie uchem), wierne grafiki kostek, link do sklepu producenta i dystrybutorów w jednym miejscu. |

## Pozycjonowanie

Anty-wzorzec: statyczne demo na YouTube i strony z samplami w sztywnych ustawieniach.
PedalTest Studio robi dokładnie to, czego one nie potrafią: **interaktywne porównanie
ustawień**, a w wizji docelowej — **prawdziwy hardware sterowany zdalnie**, co omija też
temat licencji na brzmienie (model jak wypożyczalnia/studio, do potwierdzenia z prawnikiem).
